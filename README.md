# Wahyudi — Data Engineering Portfolio

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `data-portfolio` (or use an existing repository).
2. Upload all files and folders from this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

Expected URL: `https://WahyudiLs7.github.io/data-portfolio/`

## Customize
- Update contact details and links in `index.html`.
- Update colors, spacing, and typography in `style.css`.
- Place additional images in `assets/` and reference them from `index.html`.

The project content is based on the supplied `Portfolio_DE_Wahyudi.pptx`.
